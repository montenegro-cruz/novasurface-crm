# NovaSurface CRM

## Visión

NovaSurface CRM será una plataforma web moderna orientada a la gestión integral de clientes, presupuestos, proyectos, evidencias fotográficas y facturación para empresas de limpieza y restauración mediante tecnología láser.

El sistema permitirá centralizar toda la actividad comercial, operativa y financiera en una única plataforma accesible desde cualquier dispositivo.

---

## Misión

Ayudar a NovaSurface a gestionar de forma eficiente todo el ciclo de vida de un cliente:

Lead → Cliente → Presupuesto → Proyecto → Factura → Seguimiento

---

## Objetivos de negocio

### Objetivos principales

- Centralizar la información de clientes.
- Gestionar oportunidades comerciales.
- Optimizar la generación de presupuestos.
- Gestionar proyectos y trabajos.
- Controlar la facturación y cobros.
- Mantener un histórico completo de evidencias.
- Obtener métricas para la toma de decisiones.

### Objetivos secundarios

- Reducir tareas administrativas.
- Mejorar la trazabilidad de los trabajos.
- Mejorar la experiencia del cliente.
- Facilitar el crecimiento de la empresa.

- Gestión de facturas.

- Gestión de almacén.
- Compras y proveedores.
- Control horario avanzado.
- Integración con maquinaria láser.
- Inteligencia artificial avanzada.
